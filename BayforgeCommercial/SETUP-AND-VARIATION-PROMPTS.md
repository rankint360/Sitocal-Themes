# Bayforge Commercial — 1.0.0

Commercial overhead doors & loading bays theme with 5 editable pages. Havenlift Residential uses navy and orange, residential project photography and an interactive visual-inspection checklist. Bayforge Commercial uses steel and amber, loading-bay photography, operator-system information and maintenance planning.

## Deployment
Extract the deployment ZIP with index.html at the root. It is compatible with Cloudflare Pages, Netlify and ordinary static hosting. No build command, package installation, WordPress runtime or backend is required. The existing Sitocal-Themes GitHub workflow automatically assembles this versioned deployment ZIP into the shared Cloudflare library on a push to main.

## Sitocal
Registered in the public preview library, Customize a Theme and Build from Scratch > Design & Branding. The sitocal.library-project/1 adapter exposes page copy, headings, paragraphs, FAQ summaries, captions and metadata. Saved edits must remain visible in draft previews and exported ZIPs. Native checklist inputs and disclosures remain usable in static exports; editor previews disable scripts, while normal checkbox/disclosure behavior remains available. The completion counter is a local UI enhancement and is not a safety certification.

## Source and assets
Edit source/assets/theme.css and theme.js. Content and page routes are listed in source/theme.json. All photographs and fonts are bundled locally. The source ZIP includes source/, preview artwork, asset notes and this guide. Replace sample business details and adapt any service descriptions before customer publication. Stock project photos are illustrative and are not presented as completed work by a sample business. Demo contact forms, calls, bookings and payments are disconnected.
