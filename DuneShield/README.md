# DuneShield

Renamed clone of the reference template. The design and page structure follow the reference. Includes 19 captured pages. Reference: https://theme9preview.netlify.app.

## Deploy and edit

Extract the deployment ZIP and upload the folder containing index.html to Netlify. For source-based deployment, extract the source ZIP and publish the site directory. There is no build command or package installation. Edit the HTML and assets under site. The theme uses root-relative routes, so preview it through an HTTP server.

## Demo behavior

Forms are demonstration only. Phone and email actions lead to Contact. Sample business claims are illustrative. Embedded maps were replaced with links to the public service area. See ASSET-SOURCES.json in the source ZIP for asset origins. Visual browser verification is pending.
