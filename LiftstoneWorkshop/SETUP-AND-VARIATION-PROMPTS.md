# Liftstone Workshop — 1.0.0

Garage door repair and installation theme adapted from the user-supplied https://garagedoorsrepairyuma.com/. The reference is a single-page website; this theme preserves that format. Liftstone Doors retains the reference composition, photography, service blocks, project gallery, FAQ and quote layout. Liftstone Workshop uses an independent graphite/saffron design and a new editorial composition.

## Deployment
The netlify-deploy ZIP also runs on Cloudflare Pages and other static hosts. Extract with index.html at the root. The existing shared Pages workflow automatically detects this versioned ZIP when pushed to main. No WordPress installation, build command, credentials or backend are required.

## Editing in Sitocal
Registered in Customize a Theme and Build from Scratch > Design & Branding, plus the public library. The existing sitocal.library-project/1 adapter exposes headings, paragraphs, FAQ summaries and metadata. Saved edits are rendered in draft previews and exported ZIPs. Source CSS, local photos and fonts remain portable. The editable-source ZIP contains source/, previews, this guide and asset notes.

## Demo behavior
The quote form, calls, bookings and payments are disconnected. Business contact information is fictional. Review layouts are explicitly labelled as samples. Map embeds and analytics were removed. Mobile navigation, native FAQs, anchored navigation and reduced-motion support work without WordPress. Replace business details and review any illustrative claims before publishing a customer website.
