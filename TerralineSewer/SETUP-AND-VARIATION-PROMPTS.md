# Terraline Sewer 1.0.0

Static sewer repair theme for Sitocal. 194 pages, including service, neighborhood, article, company and policy pages. Derived from the user-supplied reference; sample locality and factual copy must be reviewed before customer publication.

## Deploy
The netlify-deploy ZIP is also compatible with Cloudflare Pages and other static hosts. Extract it with index.html at the document root. Shared Cloudflare deployment is automatic from this versioned release filename through scripts/build_pages.py. No build command or secrets are needed inside the theme.

## Sitocal
Import the matching bundled library ZIP using the existing HTML adapter. The platform catalog and scrolling mockup metadata register this theme in Customize a Theme and Build from Scratch > Design & Branding. Text fields and page metadata persist in drafts and exported ZIPs. CSS, diagrams and bundled photos remain intact. All business details are samples. Phone links are intentionally disconnected; there are no payment, booking or analytics connections.

## Editable source
The editable-source ZIP includes source/, this guide and asset notes. Edit assets/styles.css for base design and assets/theme.css for theme-specific styling. All fonts and images used at runtime are local. HTML routes use root-relative links; the library assembler prefixes them for shared deployment.
